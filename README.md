# 王者荣耀 原皮立绘 / 透明立绘 / 3D 全息卡

在线预览（GitHub Pages）：**https://just-lum.github.io/wzry-holo-cards/**

打开后左侧是 125 位英雄的缩略图网格，点击任意一张即可在右侧查看 3D 全息卡；
鼠标拖动可旋转，卡片背面是统一的全息卡背。

## 内容

| 目录 | 内容 | 数量 |
|---|---|---|
| `index.html` | 全息卡合集页（WebGL 渲染，单页应用） | - |
| `layers/<英雄>/` | 成品卡的四层素材：人物 / 金框UI / 线稿 / 背景（WebP） | 125 组 |
| `shared/` | 共享卡面背景与卡片背面 | 2 |
| `viewer/` | 渲染器 `renderer.js` 与列表缩略图 | - |
| `assets/splash/` | **原皮立绘**（JPEG） | 125 张 |
| `assets/cutout/` | **透明立绘**（PNG，含 Alpha） | 125 张 |
| `faces.json` | 每位英雄的人脸锚点（用于把脸对齐到绿圈位置） | 125 条 |

成品卡共 375 个 WebP 图层文件。

## 本地运行

页面用 WebGL 加载同目录素材，**必须通过 http 打开**（`file://` 会被 CORS 拦掉，
WebGL 也无法读取跨源纹理）：

```bash
cd wzry-holo-cards
python -m http.server 8796
# 浏览器打开 http://127.0.0.1:8796/index.html
```



## 技术说明

渲染器是一个单文件 WebGL 着色器，按 RGBM 做 HDR 编码，配合 bloom 与多层视差：

- **人物层** `a = (p-.5) * 1.0 + .5 + view * 0.34`（正视差）
- **背景层** `b = (p-.5) * 0.5 + .5 - view * 0.25`（反向视差，用来做纵深感）
- **金框层** `u = p`（全幅，锁定不随视角移动）

人脸锚点（`faces.json`）记录每位英雄脸中心在原图中的坐标与脸高，构建时把脸
缩放到画布高度的 20%、并对齐到卡面 (51%, 39%) 的绿圈位置，所以每张卡的人脸
都落在同一位置、大小一致。双人物英雄（元歌、干将莫邪）用"两张脸外接框中点"
作为合成锚点，保证两张脸同时入镜。

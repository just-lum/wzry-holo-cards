# 王者荣耀 原皮立绘 / 透明立绘 / 3D 全息卡

在线预览（GitHub Pages）：**https://just-lum.github.io/wzry-holo-cards/**

打开后会自动载入首张卡。桌面左侧是可搜索的英雄目录，手机下方是横向选卡栏；
拖动可旋转、点击可翻面，卡片背面是统一的全息卡背。

## 浏览与操作

- 按英雄名、称号或原系列编号搜索，支持 `001` 这样的补零编号。
- 点击卡片旁的 ☆ 收藏，目录中的「收藏」只显示已收藏英雄。收藏和画质保存在本机。
- 用左右按钮／方向键切换当前筛选结果，按 `R` 回正；输入框和滑块保留自己的键盘操作。
- 「景深」「轮廓光」调节原有多层视差和发光效果；画质提供自动、流畅和高清三档。
- 点击 ↗ 复制当前卡片链接，`#hero=<英雄key>` 可直接定位；剪贴板不可用时提供可选中的链接。
- 加载时先显示缩略图。加载失败或超过 15 秒会显示重试入口，快速切卡不会被旧请求覆盖。
- 不支持 WebGL 时仍可查找和查看卡面预览；图形上下文恢复后会重新载入选中的英雄。

`all.html` 是旧入口，会保留查询参数和英雄定位并转到同一应用。运行目录仅来自
`heroes.json`，不会再列出无素材的「元流之子」。**125 是可用卡数；卡面上 `/130`
是原系列编号，缺号和原编号均保留。**

## 内容

## 本地运行

页面用 WebGL 加载同目录素材，**必须通过 http 打开**（`file://` 会被 CORS 拦掉，
WebGL 也无法读取跨源纹理）：

```bash
cd wzry-holo-cards
python -m http.server 8796
# 浏览器打开 http://127.0.0.1:8796/index.html
```



## 技术说明

项目保持纯静态、零运行依赖、无构建步骤。单页只创建一个 WebGL 上下文，切卡时原子
替换人物／UI／线稿纹理，共享背景复用。失败、取消和被替代的加载会释放临时资源；
显示中的卡片在新素材准备好前保留。画布尺寸由未旋转的实际布局、DPR、画质及硬件上限
共同决定，旋转不会触发画布反复分配。

画面在交互、角度收敛、素材或尺寸变化时绘制；静止后停止请求动画帧，隐藏标签页时暂停。
三个着色器的视觉计算保留，仍使用原 RGBM HDR 与两级 Bloom。

渲染器是一个单文件 WebGL 着色器，按 RGBM 做 HDR 编码，配合 bloom 与多层视差：

- **人物层** `a = p - view * (.34 + depthFactor * depth)`（随景深调整）
- **背景层** `b = (p-.5) * 0.5 + .5 - view * 0.25`（反向视差，用来做纵深感）
- **金框层** `u = p - view * .14 * max(depth, 0.)`（保留原有景深行为）

人脸锚点（`faces.json`）记录每位英雄脸中心在原图中的坐标与脸高，构建时把脸
缩放到画布高度的 20%、并对齐到卡面 (51%, 39%) 的绿圈位置，所以每张卡的人脸
都落在同一位置、大小一致。双人物英雄（元歌、干将莫邪）用"两张脸外接框中点"
作为合成锚点，保证两张脸同时入镜。

## 验证

Node 内置测试及完整素材检查不需要安装 npm 依赖：

```bash
npm test
npm run validate
```

检查覆盖目录／搜索／收藏筛选／定位，以及加载竞态、中止、超时、GPU 资源释放、画质
调整回滚和上下文丢失；素材检查核对 125 张卡的 752 个图片文件和两个页面入口。

浏览器检查使用 Python Playwright 和对应 Chromium，在临时隔离的浏览器配置中运行：

```bash
python tests/browser_smoke.py --output .verification/browser
```

脚本自动启停本机 HTTP 服务，保存截图和 JSON 报告。包含 320–1440px、手机横屏、
连续切卡、失败重试、网络超时、搜索收藏、链接历史、键盘、画质失败回滚和图形恢复。
本地无头浏览器的耗时不代表手机真机 FPS 或公网加载速度。
